# 銷售劇本

每個劇本對應一種 **客戶類型 × 銷售情境**，提供從接觸到成交的完整路徑。

## 已建立
- `new-broker-launcher.md` — 想做新 FX broker 的入場者（最高 ARR）
- `existing-broker-upgrade.md` — 既有 broker 想升級執行品質
- `pop-institutional.md` — Hedge fund / Prop desk 找 LP
- `cgse-bullion-dealer.md` — 香港金銀業貿易場 E-Trading 金商（XAU/CNH 為錨）

## 每個劇本的結構
1. **目標客戶畫像**（quantitative + qualitative）
2. **獵客來源**（哪裡找、什麼信號代表機會成熟）
3. **首次接觸話術**
4. **異議處理重點**（特別針對此類客戶）
5. **Demo 重點**（要強調什麼、避免什麼）
6. **典型成交週期 & ARR 範圍**
7. **常見死局**（什麼情況不要再追）
