# 內容素材

> 建立個人品牌的長期資產。內容 → 信任 → inbound lead。

## 三類
- `posts/` — LinkedIn 短文、Twitter thread
- `case-studies/` — 客戶案例（成單後可改寫為 anonymized study）
- `insights/` — 較長的行業洞察（部落格、newsletter）

## 命名
`YYYY-MM-DD-<主題-slug>.md`

## 發布節奏（建議）
- **LinkedIn**：每週 2-3 篇短文
- **Insights**：每月 1 篇長文
- **Case studies**：成單後 1 個月內整理

## LinkedIn 內容主題池
- AI 在 FX execution 的真實應用（vs hype）
- 中小型 broker 容易忽略的執行品質指標
- A/B Book 路由的 AI vs rule-based 對比
- XAU/CNH 為什麼是亞洲 broker 的 sleeper opportunity
- 監管變化的 broker 觀察（FCA, CySEC, FSC, ASIC）
- 客戶常問的問題（從 FAQ 改寫）
- 行業會議觀察（iFX、Finance Magnates Summits）

## 寫作原則
- **不要寫產品 ad**，寫產業觀察
- **數據要有 source**，否則不寫
- **個人觀點要有 conviction**，無痛癢的中立內容沒人讀
- **每篇引發 1 個討論問題**（增加留言互動）

