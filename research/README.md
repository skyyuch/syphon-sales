# 市場研究

> 沒有研究就沒有差異化銷售。每個高優先客戶 deal 前都要做研究。

## 三大類
- `market/` — 行業趨勢、整體市場規模、新進入者動態
- `competitors/` — 競品研究（指向 `../knowledge-base/competitors/`，本資料夾放「事件追蹤」）
- `regulatory/` — 監管變化（影響客戶買單意願的最大變數）

## 命名規範
`YYYY-MM-DD-<主題>.md`

例：
- `market/2026-05-20-xau-cnh-asia-demand.md`
- `regulatory/2026-05-20-cysec-broker-tightening.md`
- `competitors/2026-05-20-onezero-acquisition-rumour.md`

## 定期研究任務（建議節奏）
| 頻率 | 任務 |
|------|------|
| 每週 | 看 Finance Magnates、FX Week、Bloomberg FX 標題 |
| 每月 | 更新主要競品的 pricing / 功能變化 |
| 每季 | 監管變化 review（FCA、ASIC、CySEC、SFC、FINMA） |
| 每半年 | 客戶 win/loss 分析 → 反饋到 playbook |

## 研究筆記結構
```markdown
# 主題

**Source**: URL / news / 客戶口述
**Date**: YYYY-MM-DD
**Importance**: P0 / P1 / P2
**Affects**: 哪些客戶類型 / 哪個產品線

## 觀察
事實，不要評論

## 含意
對我們的銷售意味著什麼

## Action
要做什麼跟進
```
